# D455 视觉方法需求—任务—学习—晋级闭环流程图

本文与《视觉方法需求—任务—学习—晋级闭环详细设计》配套。图中“当前已具备”表示仓库已有运行链路；“设计待实现”表示需要后续确认和计划，不代表当前代码已经完成。

## 一、三层事实边界

```mermaid
flowchart LR
    A["L0 现实材料\n彩色图 / 深度 / 左右红外 / 姿态"] --> B["L1 观察材料\n深度锚点 / 彩图轮廓 / 双目证据"]
    B --> C["像素账本与候选簇\n精确三维 / 粗距轮廓 / 纯图像轮廓 / 未知"]
    C --> D["L2 认知状态\n候选 / 稳定 / 遮挡关联 / 已确认"]
    D --> E["L3 方法能力\n适用条件 / 成本 / 失败回执 / 版本"]
    E --> F["L4 实验治理\n运行 / 需求 / 任务 / 晋级记录"]
    F -."不能反写现实".-> A
```

约束：观察材料和认知候选不能直接等同于现实存在；实验报告和历史回放也不能改写当前场景事实。

## 二、需求生成与去重

```mermaid
flowchart TD
    A["分析运行包\n运行清单 / 配置 / 帧特征 / 簇特征 / 事件"] --> B{"输入有效且版本可复查?"}
    B -- 否 --> X["拒绝生成需求\n记录证据不完整"]
    B -- 是 --> C["按主体、特征、场景、失败类型聚合事件"]
    C --> D["排除启动帧、传感器无效、重复报告"]
    D --> E{"是否达到持续性门槛?"}
    E -- 否 --> Y["保留为观察事件"]
    E -- 是 --> F["生成需求候选\n当前值 / 目标值 / 差距证据 / 保护条件"]
    F --> G{"需求去重键已存在?"}
    G -- 是 --> H["合并证据\n更新需求频次与适用范围"]
    G -- 否 --> I["登记新需求\n状态=已确认或待确认"]
```

需求去重键：

```text
目标主体 + 目标特征 + 失败类型 + 场景桶 + 触发方法版本
```

## 三、任务筹办与学习状态

```mermaid
flowchart TD
    A["已确认需求"] --> B["任务筹办\n确定一个主目标和保护条件"]
    B --> C["查询适用方法\n基线 + 最多三个受控候选"]
    C --> D["练习\n确认输入、输出、评分链路"]
    D --> E{"链路正常?"}
    E -- 否 --> R["任务失败或等待补证"]
    E -- 是 --> F["尝试学习\n组合已有方法 / 有限参数 / 降级路径"]
    F --> G{"已有方法足够?"}
    G -- 是 --> H["固定回放复验"]
    G -- 否 --> I["定向学习\n只生成受控方法设计，不自动改生产代码"]
    I --> H
    H --> J["留出回放复验"]
    J --> K["在线影子验证"]
    K --> L{"硬门槛和保护条件全部通过?"}
    L -- 否 --> M["回退到适用基线\n保留失败回执和未满足需求"]
    L -- 是 --> N["按适用条件晋级方法版本"]
```

## 四、单帧实时感知与低频治理分离

```mermaid
flowchart LR
    A["每帧输入"] --> B["低成本特征\n深度可靠性 / 边界 / 运动上下文 / 缓存年龄"]
    B --> C["全画面归簇\n每像素写入账本状态"]
    C --> D["输出当前帧"]
    B --> E{"是否触发高成本刷新?\n启动 / 定时 / 局部运动 / 远场丢失 / 未知上升"}
    E -- 否 --> F["复用经过门禁的缓存"] --> C
    E -- 是 --> G["选择全帧、局部、分片或保守降级"]
    G --> H["生成/复用双目证据\n失败时保留可信轮廓"]
    H --> C
    D --> I["按时间窗聚合指标"]
    I --> J["仅在稳定差距时进入需求治理"]
```

实时感知环不应把每帧、每个像素直接创建为任务；需求治理环只处理经过时间窗聚合的稳定差距。

## 五、方法生命周期

```mermaid
stateDiagram-v2
    [*] --> 探针
    探针 --> 候选: "输入和输出契约通过"
    候选 --> 影子: "固定回放与留出回放通过"
    影子 --> 已晋级: "在线影子通过"
    已晋级 --> 暂停: "新场景出现未解释退化"
    暂停 --> 已晋级: "补证后恢复"
    暂停 --> 已回退: "保护条件或硬门槛失败"
    候选 --> 已回退: "固定回放失败"
    影子 --> 已回退: "在线影子失败"
    已回退 --> 探针: "修订后生成新版本"
```

晋级始终带适用桶；例如“慢速相机平移已晋级”不等于“局部运动已晋级”。

## 六、首轮手部遮挡—重现验证链

```mermaid
flowchart TD
    A["冻结真实回放和版本"] --> B["用当前基线复现失败"]
    B --> C{"失败可复现?"}
    C -- 否 --> D["暂停需求生成\n补充或修订数据"]
    C -- 是 --> E["登记单一主目标需求\n轮廓归属连续性"]
    E --> F["顺序运行基线、有限缓存/重投影、局部重建候选"]
    F --> G["比较近场、远场、账本、性能、轮廓连续性"]
    G --> H{"固定回放通过?"}
    H -- 否 --> I["保留失败回执\n进入下一候选或结束任务"]
    H -- 是 --> J["未参与选择的留出回放"]
    J --> K{"保护条件通过?"}
    K -- 否 --> I
    K -- 是 --> L["在线影子运行"]
    L --> M{"实时状态通过?"}
    M -- 否 --> I
    M -- 是 --> N["按适用桶晋级\n下一次相同条件自动选择"]
```
