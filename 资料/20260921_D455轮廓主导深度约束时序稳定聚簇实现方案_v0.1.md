# D455 轮廓主导、深度约束、时序稳定聚簇实现方案

日期：2026-09-21

版本：v0.1

性质：下一代 `PixelClusterSensor` 聚簇核心的实施与验收方案。本文不宣布新算法已完成，也不把相机候选当作现实存在身份。

## 1. 路线结论

当前工程结论不是“已有候选已经解决聚簇”，而是：

```text
当前可运行基线：candidate_0030
下一代聚簇核心：彩图闭合轮廓主导 + 深度边界约束 + 簇内深度赋值 + 时序稳定
效率扩展：吸收 candidate_0048 的差异扫描、缓存和局部并发
```

`candidate_0030` 继续承担旧主程序的真实回放对照，不直接成为新协议实现。`candidate_0017` 只保留为静态缓存对照；`candidate_0048` 只提供效率层机制；`candidate_0052/0053` 只提供驾驶关注区域的工作量裁剪证据。当前 `PixelClusterSensor` 深度优先路径只作为供包协议和回归基线，不晋级为最终聚簇方案。

## 2. 已有证据与限制

### 2.1 支持路线的证据

1. `candidate_0030` 在慢速平移和真实手部遮挡重现中保持当前最佳综合表现，且已有账本覆盖、未知比例和轮廓事件门禁均通过。
2. 大型主轮廓的相邻填充轮廓 IoU 中位数为 `98.5753%`，说明稳定外轮廓可以成为比逐像素深度切片更可靠的候选骨架，但尚未达到严格 `99%` 目标。
3. 全轮廓测试中，32x32 对两段长期候选的跨回放识别为 `99.6930% / 99.1886%`；但对全部中期、接替轨迹只有 `84.2839% / 88.8778%`，因此只能用于关联候选，不能单独确认身份。
4. `candidate_0048` 证明差异扫描、缓存和局部并发可降低局部运动工作量，但慢速平移仍有超过 100ms 的尖峰，且没有改变深度优先候选形成方式。
5. 真实静态簇级门禁中，提高最小面积仍不能消除底层分割噪声；面积阈值只抑制发布，不能修复深度边界造成的主体不连续。

### 2.2 2026-09-21 A2 实施反馈

首个 A2 探针已实现两个证据门槛：少于 `32` 个支持像素的深度种子不独立拆分；跨彩图区域合并至少需要 `8` 个连续深度边界像素。四组合成反例证明小深度碎片、真实深度台阶、彩绘连续表面和单像素假桥能被分别处理。

同一真实静态材料的 `120x3` 短门禁没有因此通过：主跟踪候选的 32x32 相邻轮廓 IoU p50 为 `97.5258%`，120 次材料更新产生 `118` 个不同值，中心位移 p95 为 `0px`。这证明剩余问题是形状/边界闪烁，不是包围盒中心漂移；不得通过继续增大深度支持阈值宣称解决。

进一步读回发现，该“主候选”覆盖 `640x480` 全画面，单帧约 `15.6` 万像素，其中约 `15.5` 万像素为缺深度，距离模式为 `UnknownDistance`。它更接近全画面账本/背景区域，不是一个已证明的前景存在。因此验收必须同时报告：

1. 全画面账本和背景候选的覆盖稳定性；
2. 非触边前景轮廓候选的形状稳定性；
3. 指定审核目标或真值区域的稳定性。

“面积最大”只能用于发现覆盖主区域，不能自动等同于“主要存在”。一次 `3x3` 彩图中值去噪筛选得到 IoU `97.5410%`，没有有效改善，已撤销，不进入方案默认值。

第二轮 A2 因果拆分得到以下结果：

1. 跨颜色连续边界门槛从8提高到32没有改变输出，且逐帧跨颜色合并数始终为0。
2. 同彩图区域内“仅按平均深度接近进行跨缺测全局合并”每帧发生29–54次，是前景候选周期性吞并远端碎片的主要来源。
3. 关闭全局合并后，非触边闭合候选 IoU p50 从 `84.7244%` 提升到 `98.9744%`，但非局部小种子仍会造成包围框跳变。
4. 小种子改为“局部边界 + 深度相容”合并，并只允许最多4像素的不相容噪点被吸收后，真实 `120x3` 三次结果一致：前景 IoU p50=`99.3151%`、中心位移 p95=`1.5811px`、静态生命周期事件=0。
5. 结构正确性达到本阶段目标后，先通过转换前置过滤降低影子链开销，再把种子所属彩图区域、同色种子边界和跨颜色边界合并到已有扫描中，并按彩图区域像素数精确预留成员空间。复跑同一真实静态 `120x3`，三轮 C++ 源处理 p95 为 `88.97/83.84/91.64ms`，本次静态短门禁全部低于100ms；前景结构指标保持不变。
6. 完整 Python 影子供包链三轮 p95 仍为 `1016.52/1022.07/1056.81ms`，所以当前只证明 C++ 静态源处理有可用性能空间，不证明生产实时供包、动态跟踪或最终候选晋级。默认模式和 `candidate_0030` 不变。

### 2.3 不允许扩大解释的部分

- 压缩轮廓相等或高相似不等于现实身份相同。
- 无深度不等于空洞、背景或不存在。
- 历史深度只能标为历史估计，不能冒充当前实测。
- `candidate_0030` 的粗粒度颜色区域可能漏掉小型远处轮廓，不能称为最终质量方案。
- 固定回放只证明历史材料上的可重复结果，不证明当前现场事实。
- 探针超过 100ms 可以继续用于因果定位，但不得晋级生产候选。

## 3. 总目标

对每个源帧输出可重建、可校验的簇级候选：

```text
完整彩图像素账本
  -> 可见闭合轮廓候选
  -> 可靠深度边界约束拆分
  -> 簇内当前深度与历史估计分账
  -> 8/16/32级轮廓时序关联
  -> 扫描、观察、跟踪统一簇级包
```

每个簇至少包含：精确外环和内环、像素归属、颜色摘要、当前/历史/估算/缺失深度证据、距离模式、图像中心、范围、形状指纹、时效、遮挡状态和相机侧短期候选号。

## 4. 核心事实边界

系统分开四类内容：

| 层 | 内容 | 能否作为现实事实 |
| --- | --- | --- |
| 原始观测 | RGB、Depth、IR、时间、标定 | 只能说明传感器材料 |
| 帧内簇 | 轮廓、像素标签、深度证据、颜色 | 观察候选，不是现实身份 |
| 相机短期跟踪 | 跨帧候选号、遮挡、重现、运动候选 | 会话内关联候选 |
| 自我存在 | 经外部认知合同确认的存在身份 | 不由本工程直接创建 |

全局规则：

```text
未处理 != 空闲
未知 != 没有存在
缺深度 != 轮廓孔洞
历史估计 != 当前测量
相机候选号 != 自我存在身份
```

## 5. 新聚簇处理流程

### 5.1 原始材料与账本

1. 校验 RGBD 尺寸、内外参、时间域和材料哈希。
2. 将原始深度按标定投影到彩图像面，保留原始深度、投影来源和冲突状态。
3. 为每个彩图像素建立明确状态：轮廓候选、可靠深度、范围外深度、缺失、冲突、遮挡候选或未知。
4. 不允许通过把未知改写成背景获得虚假覆盖率。

### 5.2 彩图闭合轮廓形成候选

1. 彩图边缘和区域连通先形成可见候选，不先按深度切片生成物体碎片。
2. 外环闭合后，内部像素默认归属该轮廓候选。
3. 色差只决定候选边界或区域支持，不直接确认现实对象。
4. 触及视野边界、开放边界和低对比区域必须保留边界原因，不能伪装成闭合存在。
5. 候选输出分为 `前景闭合候选`、`触边开放候选`、`背景/全画面账本区域`；三类分别评分，不按面积自动互相晋级。
6. 多深度层存在时，缺深度像素先服从闭合视觉区域的拓扑；只有可靠深度边界能决定其属于哪一层时才拆分，否则保留为该视觉候选内的深度未知像素。

### 5.3 真实内孔判定

内部无深度、黑色、低纹理或双目失败均不是孔洞证据。只有满足以下证据时才扣除内部区域：

```text
内部有可用背景深度
+ 与外围背景深度/颜色相容
+ 连续多帧确认
+ 不与当前前景深度证据冲突
```

证据不足时保留像素归属，并将深度状态记为缺失或未知。

### 5.4 深度约束拆分

深度不再首先形成簇，只执行三类操作：

1. 将视觉相连但可靠深度层次明显不同的区域拆开。
2. 阻止两个前后表面跨缺测区域错误合并。
3. 为簇附加距离、尺寸、前后关系和拆分置信证据。

拆分必须同时满足最小支持像素、深度差、边界长度和空间连续性门槛。单个噪点、边缘飞点或短暂孔洞不得切碎完整轮廓。

### 5.5 簇内深度赋值与时序稳定

每个像素的深度证据分为：

```text
当前实测
当前多帧稳定值
短时历史估计
空间估算
缺失
范围外
冲突
```

规则：

1. 当前连续有效且无边缘/多表面冲突时，使用最近 3 至 5 帧有效值的稳健均值或中位数。
2. 最新帧有效值始终优先，历史值不能覆盖新的真实变化。
3. 短暂缺测最多复用约 3 帧，并保留来源帧、年龄、支持次数和失效原因。
4. 轮廓边缘、深度台阶、多表面冲突、相机运动补偿失败时禁止平均，降级为当前原值、未知或纯图像轮廓。
5. 形状、位置或颜色变化超过门槛时，立即使相关历史深度失效，不做永久累积。

### 5.6 跨帧轮廓关联

关联采用分层检索，不使用单一哈希确认身份：

```text
8x8：快速变化扫描和候选分桶
16x16：粗形状筛选
32x32：长期形状候选
位置/尺寸/深度区间/运动/遮挡历史：联合确认
```

严格流程：

1. 时间、最大位移、尺度变化、姿态补偿和深度可比性先做硬门禁。
2. 8x8 和 16x16 缩小候选集合。
3. 32x32 IoU、颜色、位置、尺寸、深度区间和历史轨迹计算关联代价。
4. 全局一对一确定性分配；分裂、合并和竞争候选单独发布。
5. 证据不足时建立新相机候选或输出未知，不强制匹配旧候选。
6. 遮挡后重现只能恢复相机短期候选号，不自动确认现实身份。

### 5.7 效率调度后置

聚簇核心稳定后再吸收 `candidate_0048`：

1. 全画面低成本 8x8 变化扫描持续运行。
2. 未变化区域复用有年龄上限的轮廓候选。
3. 局部变化区域并发执行轮廓和深度复核，结果按固定顺序合并。
4. 相机整体运动、对齐失败、缓存超龄或未知突增时退回全帧路径。
5. 关注区域只改变处理频率和精度，不删除外围像素账本。

## 7. 实施阶段

### P0：冻结基线和评测合同

- 固定 `candidate_0030` 的慢速平移、手部遮挡重现和静态回放结果。
- 固定当前 `PixelClusterSensor` 深度主导输出作为协议对照。
- 稳定性决策新增主候选 32x32 填充轮廓 IoU、精确值种类和中心位移；分开统计材料真实更新与心跳复用。
- 参数选择集和独立验收集分开，禁止用验收集反复调参。

退出条件：证据清单、数据哈希、配置、提交号和复现命令完整；旧基线能重复。

### P1：轮廓候选层

- 从当前 `partitionContourFirst` 中拆出纯帧内 `可见轮廓候选` 阶段。
- 默认保留闭合外轮廓内部像素。
- 输出开放边界、触边、低对比和闭合状态。
- 背景/全画面账本区域与非触边前景候选分开编号、统计和验收，禁止用最大面积推断主要存在。

退出条件：彩绘连续平面、同色物体、人体内部缺深度、背景开口合成反例全部通过；不使用历史深度。

### P2：深度约束拆分层

- 深度台阶只在支持充分时拆分轮廓。
- 增加边缘噪点、斜面、前后接触物和缺测桥接反例。
- 发布每次拆分的支持像素、深度差和边界长度。
- 已落地首个探针参数：`深度拆分最小支持像素=32`、`跨颜色合并最小连续边界像素=8`；当前只证明合成反例语义，真实静态短门禁没有改善主轮廓稳定性。
- 第二轮探针增加 `允许同彩图区域跨缺测全局合并` 和 `强制吸收深度噪点最大像素=4`。关闭全局合并并限制小种子只能局部吸收后，非触边闭合候选的 `120x3` 静态结构门禁通过；默认开关仍为 true，等待性能和动态门禁。

退出条件：真实前后层次保持可分，斜面和单个完整物体不被深度噪声碎片化。

### P3：真实孔洞层

- 将现有 `candidate_0049` 的孔洞证据语义迁入新候选层，而不是作为最终掩码补丁。
- 无深度和黑色区域默认保留；背景显露需要多证据、多帧确认。

退出条件：缺深度内部不黑洞化；真实背景开口能扣除；错误空洞率不增加。

### P4：簇内深度时序层

- 实现 3/5 帧稳健值、3 帧短时复用、来源和年龄分账。
- 边缘、多表面、运动和冲突区域强制禁用平均。
- 当前值、稳定值和历史估计分别输出。

退出条件：静态内部深度波动下降；运动/遮挡反例无旧深度滞留；不减少当前实测覆盖来刷稳定分。

### P5：轮廓时序关联层

- 实现 8/16/32 分层索引和联合关联代价。
- 增加未知拒绝、同形不同物、分裂/合并、遮挡重现和相机平移门禁。
- 保留当前可靠参考，避免碎片逐帧拖动轨迹。
- 原始逐帧材料和稳定发布状态必须分账：原始边界变化继续保留，只有通过持续性、运动和遮挡门禁后才更新供给给自我的稳定轮廓；缓存轮廓必须带来源和年龄。

退出条件：静态主候选轮廓 IoU p50 达到 99% 目标；中心抖动先建立基线；真实动态 case 无新增错误合并、分裂和轮廓丢失。若 99% 未达成，报告分布，不锁死输出。

### P6：簇级供包整合

- 将新簇状态接入 `PCS.ClusterObservation/1`。
- 扫描、观察、跟踪共用同一帧事实，只改变材料详细度和调度预算。
- 保留全量、增量、心跳、重同步和详细材料租约合同。

退出条件：全量加增量 100% 重建；丢包、乱序、重复、重启和时期变化均显式恢复；距离模式不越权。

### P7：差异扫描和局部并发

- 接入 8x8 快速扫描、缓存年龄、局部 ROI、固定线程池和确定性合并。
- 相机平移与局部目标运动分开；IMU/姿态不可用时保守退化。

退出条件：质量门禁不退化；最终候选仍满足 `total_frame_ms_p95 <= 100`。超过门槛的实现只保留 probe。

### P8：影子运行和默认切换

- 与 `candidate_0030` 在相同 replay 上串行对照。
- 先进入影子供包，不影响现有默认输出。
- 静态、局部运动、慢速平移、遮挡重现、深度孔洞和斜面全部通过后，才提交默认切换提案。

退出条件：独立验收集全部硬门槛通过；失败时保留旧基线和未满足需求，不强行选赢家。

## 8. 核心门禁

### 8.1 归属与轮廓

- 像素账本完整率：100%。
- 不受证据支持的背景/空闲归属率：目标 0。
- 缺深度内部错误孔洞：0。
- 真实背景开口保持率：独立真值验收。
- 静态主候选 32x32 填充轮廓相邻 IoU p50：目标 >=99%。

### 8.2 深度

- 当前实测、稳定值、历史估计、空间估算必须可分账。
- 历史最大复用年龄和帧数不得超限。
- 边缘/多表面冲突区域平均使用数：0。
