# D455 需求特征值方法流程说明

本文把当前项目需求改写为“存在对象、特征类型、特征值、状态迁移、方法函数、实现流程、验证方式”的中文规格。本文是资料层说明，不直接要求把源码符号批量重命名；后续如果要改源码命名，应单独做重构计划和回归验证。

## 一、总目标

项目目标是把 D455 视频输入转换为可验证的全画面像素归簇结果：

- 每个像素都应有明确归属。
- 近处且深度可靠的区域输出精确三维空间簇。
- 远处、无深度、深度不稳定或深度超出可靠范围的区域，不伪造精确距离，而是降级为粗距轮廓或纯图像轮廓。
- 相机移动、局部遮挡、目标重现时，轮廓归属应尽量稳定，不产生明显错位、滞后和整帧卡顿。
- 所有改进必须能由固定回放、特征表、评分结果和排行榜复查。

## 二、目标分解

| 子目标 | 中文目标名 | 说明 | 验证方向 |
|---|---|---|---|
| 全像素归属 | 全画面归簇 | 每个像素至少属于一个簇或背景状态 | 覆盖率、未知率 |
| 近处精度 | 可靠深度三维簇 | 可靠深度范围内输出三维簇 | 深度有效率、近场得分 |
| 远处保留 | 远场轮廓保持 | 深度不可靠时保留二维轮廓和粗距证据 | 远场得分、轮廓丢失事件 |
| 降级正确 | 不伪造精确距离 | 无可靠证据时降级，不输出假三维 | 距离模式、证据状态 |
| 运动稳定 | 移动时不滞后 | 相机移动和局部运动时减少错位和残影 | 运动状态、缓存年龄、轮廓丢失 |
| 性能可用 | 单帧耗时受控 | 避免刷新、双目匹配、诊断导出造成尖峰 | 帧耗时中位数、九十五分位、最大值 |
| 可复查 | 自动实验闭环 | 运行结果可被固定数据集和脚本复现 | 运行清单、配置快照、评分文件 |

## 三、存在对象

| 存在对象 | 含义 | 主要特征 |
|---|---|---|
| 画面 | 单帧输入和处理结果 | 画面编号、画面尺寸、总像素数、处理耗时 |
| 像素 | 画面中的最小归属单位 | 像素归属、簇编号、未知状态 |
| 观察簇 | 一组同类归属像素 | 簇类型、面积、边界框、中心、深度统计 |
| 深度证据 | 来自深度图的可靠性材料 | 有效深度比例、深度均值、深度范围、稳定性 |
| 彩图轮廓 | 来自彩图或红外图的二维轮廓材料 | 轮廓面积、边界框、颜色归属、边缘一致性 |
| 双目证据 | 左右红外视差产生的粗距材料 | 是否构建、是否复用、是否失败、粗距区间 |
| 局部刷新区域 | 运动或异常触发的局部处理范围 | 区域面积、候选面积、是否过大、是否为空 |
| 运动上下文 | 相机和画面的运动状态 | 视觉位移、惯性角速度、加速度变化、运动等级 |
| 缓存轮廓 | 上一批可复用的彩图轮廓和证据 | 缓存年龄、复用次数、证据保留状态 |
| 候选方案 | 一组参数或策略配置 | 候选编号、用途、风险、评分结果 |
| 运行记录 | 一次实验运行 | 运行编号、配置、指标、事件、评分 |

## 四、特征类型与特征值

### 四点一 归属类型特征

| 特征名 | 中文特征值 | 含义 |
|---|---|---|
| 簇空间类型 | 精确深度三维簇 | 深度可靠，可输出三维空间簇 |
| 簇空间类型 | 粗距双目轮廓 | 深度不够可靠，但有双目粗距或远近顺序证据 |
| 簇空间类型 | 纯图像轮廓 | 只有二维视觉轮廓，距离未知 |
| 簇空间类型 | 背景平面 | 被判定为近处或室内背景平面 |
| 簇空间类型 | 远场背景 | 远处剩余区域已有粗背景归属，但不是明确目标 |
| 簇空间类型 | 深度孔洞候选 | 深度缺失但可能属于可见物体 |
| 簇空间类型 | 未知 | 暂时不能归属，应尽量减少 |

### 四点二 距离模式特征

| 特征名 | 中文特征值 | 含义 |
|---|---|---|
| 距离模式 | 精确三维距离 | 近处可靠深度可用 |
| 距离模式 | 粗略距离区间 | 远处只给区间，不给精确值 |
| 距离模式 | 相对远近顺序 | 只判断哪个轮廓更近或更远 |
| 距离模式 | 距离未知 | 保留轮廓，但不输出距离 |

### 四点三 证据状态特征

| 特征名 | 中文特征值 | 含义 |
|---|---|---|
| 深度证据状态 | 深度可靠 | 深度有效且稳定 |
| 深度证据状态 | 深度不稳定 | 深度波动或与边界不一致 |
| 深度证据状态 | 深度缺失 | 像素或区域没有深度值 |
| 深度证据状态 | 深度超限 | 超出当前可靠精度范围 |
| 双目证据状态 | 已构建 | 当前区域成功计算出双目粗距 |
| 双目证据状态 | 已复用 | 当前区域复用了历史双目证据 |
| 双目证据状态 | 已保留 | 局部刷新时保留了重叠旧证据 |
| 双目证据状态 | 构建失败 | 尝试构建但失败 |
| 双目证据状态 | 已丢弃 | 被策略过滤掉 |
| 双目证据状态 | 无证据 | 没有双目证据 |

### 四点四 局部刷新特征

| 特征名 | 中文特征值 | 含义 |
|---|---|---|
| 局部刷新状态 | 有效局部区域 | 可以只刷新局部 |
| 局部刷新状态 | 区域过大 | 接近整帧，不适合局部刷新 |
| 局部刷新状态 | 区域为空 | 没有有效刷新区域 |
| 局部刷新状态 | 已跳过被拒绝运动区域 | 纯运动触发且区域无效时复用缓存 |
| 局部刷新状态 | 全帧回退 | 局部刷新失败后退回整帧处理 |

### 四点五 运动状态特征

| 特征名 | 中文特征值 | 含义 |
|---|---|---|
| 运动状态 | 静止 | 画面和惯性信号稳定 |
| 运动状态 | 相机平移 | 整体画面移动，局部差分容易扩散 |
| 运动状态 | 局部运动 | 局部目标或遮挡物移动 |
| 运动状态 | 剧烈晃动 | 运动强，缓存和局部刷新风险高 |
| 运动状态 | 未知 | 证据不足，不能可靠判断 |

### 四点六 性能与质量特征

| 特征名 | 典型特征值 | 含义 |
|---|---|---|
| 覆盖率 | 百分比 | 非未知像素占比 |
| 未知率 | 百分比 | 未知像素占比 |
| 帧耗时 | 毫秒 | 单帧处理总耗时 |
| 轮廓丢失次数 | 整数 | 目标轮廓消失事件数 |
| 合并事件次数 | 整数 | 多目标误合并风险 |
| 分裂事件次数 | 整数 | 单目标误分裂风险 |
| 缓存年龄 | 帧数 | 当前缓存距离来源帧的间隔 |
| 局部刷新面积 | 像素数或百分比 | 局部刷新是否足够小 |

## 五、达成特征值的方法函数

本文用中文方法名描述当前实现中对应的处理职责。每个方法必须有输入证据、输出特征值和失败状态。

| 中文方法函数 | 输入 | 主要改变的特征值 | 失败或降级状态 |
|---|---|---|---|
| 生成可靠深度锚点掩码 | 原始深度、滤波深度、阈值配置 | 深度证据状态、可靠深度像素 | 深度不稳定、深度缺失 |
| 生成边界分析 | 灰度图、深度图、边缘阈值 | 边界状态、候选切分边界 | 边界不明确 |
| 提取观察材料 | 深度图、边界掩码、相机参数 | 观察簇候选、候选面积、候选深度 | 候选过小、候选过大、候选贴边 |
| 用彩图轮廓修正深度材料 | 观察材料、彩图轮廓、深度图 | 簇形状、颜色归属、深度簇边界 | 颜色证据不足、轮廓不匹配 |
| 估计双目轮廓距离 | 彩图轮廓、左红外、右红外、相机参数 | 双目证据状态、距离模式 | 构建失败、距离未知 |
| 计算运动刷新区域 | 当前运动签名、缓存运动签名、面积阈值 | 局部刷新状态、局部刷新面积 | 区域为空、区域过大 |
| 合并局部刷新轮廓 | 历史轮廓、新轮廓、局部刷新区域 | 缓存状态、双目证据状态、轮廓状态 | 证据失配、需保留旧证据 |
| 过滤无双目证据碎片 | 局部刷新后轮廓、双目证据 | 双目证据状态、轮廓保留状态 | 丢弃无证据碎片；需要视觉复核 |
| 构建全画面归簇图 | 近场材料、远场材料、彩图轮廓、背景规则 | 像素归属、簇空间类型、覆盖率、未知率 | 远场背景归属、未知 |
| 读取姿态与运动信号 | 加速度、角速度、视觉位移 | 运动状态、姿态状态、相机平移风险 | 设备无惯性数据、运动状态未知 |
| 写出分析特征表 | 运行结果、元数据、性能记录 | 画面特征表、簇特征表、事件表 | 数据缺失、帧集合不一致 |
| 计算运行评分 | 特征表、评分权重、硬门槛 | 通过状态、总分、分项得分 | 硬门槛失败、回归风险 |

## 六、特征值迁移规则

### 六点一 近场深度迁移

```text
深度证据状态 = 深度可靠
并且候选材料面积有效
并且深度边界与视觉边界不冲突
=> 簇空间类型 = 精确深度三维簇
=> 距离模式 = 精确三维距离
```

如果深度缺失、深度超限或深度不稳定：

```text
不能输出精确三维距离
必须转入粗距双目轮廓、纯图像轮廓、远场背景或未知
```

### 六点二 远场轮廓迁移

```text
彩图轮廓存在
并且双目证据状态 = 已构建 / 已复用 / 已保留
=> 簇空间类型 = 粗距双目轮廓
=> 距离模式 = 粗略距离区间 或 相对远近顺序
```

如果双目证据失败但轮廓仍可信：

```text
簇空间类型 = 纯图像轮廓
=> 距离模式 = 距离未知
```

### 六点三 局部刷新迁移

```text
运动状态 = 局部运动
并且局部刷新状态 = 有效局部区域
=> 只刷新局部轮廓
=> 尝试构建或复用双目证据
```

```text
运动状态 = 相机平移
并且局部刷新状态 = 区域过大 / 区域为空
并且触发来源只是运动
并且已有缓存轮廓
=> 局部刷新状态 = 已跳过被拒绝运动区域
=> 复用缓存轮廓
```

如果触发来源是未知率升高、远场丢失、启动帧或定时刷新：

```text
不能被纯运动跳过规则拦截
必须继续执行对应恢复流程
```

### 六点四 缓存与滞后迁移

```text
缓存年龄持续升高
并且运动状态不是静止
=> 滞后风险升高
```

```text
缓存复用后轮廓丢失次数不增加
并且远场得分保持
并且帧耗时下降
=> 缓存策略可保留
```

如果轮廓丢失、错位或远场得分下降：

```text
缓存策略不能晋级
需要局部刷新、分片刷新或运动状态门控
```

## 七、实现流程

```text
一、采集输入
  彩色图、深度图、左红外图、右红外图、可选姿态信号

二、生成低成本基础特征
  深度可靠性、边界、运动状态、缓存年龄

三、生成候选材料
  深度候选、彩图轮廓候选、远场候选、背景候选

四、判断证据等级
  可靠深度、双目粗距、纯图像轮廓、背景、未知

五、构建全画面归簇图
  为每个像素写入簇编号和簇空间类型

六、按事件刷新高成本特征
  运动触发、未知率升高、远场丢失、定时刷新、启动刷新

七、做状态迁移
  构建证据、复用证据、保留证据、降级证据、过滤碎片

八、输出分析包
  运行清单、配置快照、画面特征表、簇特征表、事件表、评分结果

九、选择候选方案
  只从通过硬门槛的候选中选择阶段性赢家
```

## 八、验证门槛

| 验证项 | 通过条件 | 失败含义 |
|---|---|---|
| 全画面归属 | 覆盖率达到门槛，未知率低于门槛 | 像素归属不完整 |
| 近场质量 | 近场精确深度簇保持 | 为远场优化破坏近场 |
| 远场保持 | 远场轮廓和粗距证据不丢失 | 远处目标被吞掉或降级过度 |
| 运动稳定 | 轮廓丢失次数不增加 | 缓存或刷新策略滞后 |
| 性能 | 帧耗时九十五分位不超过门槛 | 存在卡顿风险 |
| 局部刷新安全 | 不丢弃带双目证据的真实目标 | 局部刷新破坏目标 |
| 候选晋级 | 固定回放中总分和硬门槛通过 | 只适合探针，不适合生产 |

## 九、需求到结构的最小映射

```text
业务目标：每个像素有归属
存在对象：像素、观察簇、画面
特征类型：像素归属、簇空间类型、未知率
特征值：精确深度三维簇、粗距双目轮廓、纯图像轮廓、背景、未知
方法函数：构建全画面归簇图
验证方式：覆盖率、未知率、画面特征表
```

```text
业务目标：远处不伪造精确距离
存在对象：彩图轮廓、双目证据、观察簇

特征值：粗略距离区间、相对远近顺序、距离未知

验证方式：远场得分、双目失败事件、簇特征表
```

```text
业务目标：相机移动时减少滞后
存在对象：运动上下文、缓存轮廓、局部刷新区域
特征类型：运动状态、缓存年龄、局部刷新状态
特征值：相机平移、局部运动、已跳过被拒绝运动区域、有效局部区域
方法函数：读取姿态与运动信号、计算运动刷新区域、合并局部刷新轮廓
验证方式：轮廓丢失次数、帧耗时、局部刷新面积、缓存复用次数
```

## 十、当前结论

本项目的需求可以用特征、特征值和状态迁移表达。后续新增算法不应只描述为“更稳定”“更快”“更准”，而应写成：

```text
改变哪个存在对象？
改变哪个特征？
原特征值是什么？
目标特征值是什么？
由哪个方法函数改变？
需要什么输入证据？
失败后降级到哪个特征值？
用哪个运行记录和评分指标验证？
```

只有这些槽位都能填上，才应进入实现或候选方案。
