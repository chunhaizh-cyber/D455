# D455 二值轮廓居中压缩与静态相似度测试报告 v0.1

## 一、结论

本轮已确认：

1. 最终稳定轮廓可以按 `observation_id` 分离，转换成黑白二值图，居中到最小 8 倍数宽高的矩形画布，并无损压缩为 `N` 个 `uint64_t`。
2. 每个 `8x8` 块正好占 8 字节，压缩载荷相对居中后的 8-bit 二值图固定为 `8:1`；本轮 1059 个轮廓的载荷为 5,079,600 bytes，含 88 字节文件头后共 5,172,792 bytes。
3. C++ 在线统计与 Python 从压缩位重新计算的 1059 个轮廓结果完全一致，格式、块数、padding 位和前景 popcount 校验全部通过。
4. 相同固定回放重复执行两次，两次各生成 1059 个文件，文件名无缺失、无新增，1059/1059 个文件 SHA-256 完全相同；轮廓 CSV 和帧汇总 CSV 的 SHA-256 也分别相同。现有处理逻辑对同一输入是确定的。
5. 静止场景的连续输入帧经过现有逻辑后，轮廓仍有明显差异。全部同 ID 相邻轮廓的前景 IoU 中位数为 88.6134%，最差为 4.0848%；不能宣称当前所有轮廓已稳定。
6. 大型主轮廓可以很稳定，例如 `contour_id=1` 的相邻 IoU 中位数为 98.5753%、最小值为 94.7642%；但小碎片、边缘区域和持续变形的轮廓稳定性明显较差。

因此，本轮同时证明了“压缩和比较链路可靠”与“当前轮廓输出仍存在真实帧间波动”。二者必须分开，不能把工具链确定性误写成轮廓已经稳定。

## 三、实现口径

### 3.1 二值轮廓

每帧按稳定 `observation_id` 分别处理：

```text
稳定轮廓
→ 填充成单轮廓黑白二值图
→ 扣除已确认真实背景穿孔
→ 裁剪最小前景包围框
→ 放到最小 8 倍数宽高画布中央
→ 每个 8x8 块压成一个 uint64_t
→ 保存 frame_id + contour_id + 原始 bbox + 压缩载荷
```

居中只消除原画面中的整体平移，不缩放轮廓，也不改变轮廓内部前景或缺口。原始包围框位置保留在 88 字节文件头中，可以同时分析位置变化和归一化后的形状变化。

### 3.2 相似度

当同一 ID 的两帧包围框尺寸不同时，先把两个轮廓再次居中到共同的最小 8 倍数画布，再计算：

- Hamming 一致率：全部二值位相同的比例；
- 前景 IoU：前景交集除以前景并集；
- 变化像素数：两个二值图异或后的非零像素数。

Hamming 一致率包含黑色背景，可能因为背景多而虚高。前景 IoU 才是本报告判断轮廓形状稳定性的主指标。

## 七、原因判断

### 已确认

1. 同一固定输入重复运行输出完全一致，因此不是当前程序的随机线程时序或非确定性算法导致。
2. 居中后仍有低 IoU，因此这些低值不是轮廓在画面中整体平移造成。
3. 每帧轮廓数较稳定，但部分 ID 发生接替，同时同一长期 ID 的形状也会剧烈变化。

### 高概率原因

静态输入序列本身仍包含深度、IR 边缘和有效深度孔洞的帧间噪声。当前候选生成使用深度切片、边界和面积阈值；噪声使局部像素跨过阈值后，连通域可能扩张、缩小、换片或与相邻片段重新组合。tracker 能保留历史 ID，但不会把同一 ID 的轮廓形状锁定为一个规范模板，因此会出现：

```text
输入边界/深度支持变化
→ 候选连通域形状变化
→ tracker 仍匹配到旧 ID，或旧小片段消失后生成新 ID
→ 居中二值轮廓 IoU 下降
```

这个因果判断与前一阶段“深度边缘噪声和孔洞不能靠简单平均全部消除”的结果一致，但本轮还没有逐跳变帧关联 depth edge、IR edge、anchor 和 split boundary，因此不能把责任只归给某一个传感器或某一个阈值。

## 八、下一步

1. 在 `.b8x8` 跳变帧自动导出对应的 depth edge、IR edge、anchor mask 和 split boundary，建立低 IoU 的直接来源证据。
2. 把轮廓分为“长期主存在”和“小碎片候选”两个统计桶；短寿命碎片不能与主轮廓平均后宣布整体稳定。
3. 在相机姿态和画面状态确认静止时，对同一 ID 的居中二值轮廓建立有限历史模板或逐位多数表决；只有连续多帧支持的形状变化才更新模板。
4. 真实运动或遮挡出现时必须退出静态模板保持，避免把稳定滤波变成轮廓滞后。
5. 后续可直接对 `uint64_t[N]` 做 XOR + popcount，作为快速“扫描发现变化”入口；但尺寸跨 8 像素边界时仍要按内容中心重新对齐。

本轮不修改现有分割阈值，也不把任何候选晋级为 best。它建立的是下一层轮廓稳定性测量基线。
