# D455 全轮廓分级压缩与存在区分测试报告 v0.1

## 一、结论

本轮完成了“把其他轮廓加入比较”和“压缩后的数据能否区分存在候选”两项测试。结论如下：

1. 全轮廓测试链已覆盖两段静态长时回放中的53个不同 `contour_id`、72个段内 track、13139条轮廓帧记录和13067个连续8级帧对，批量处理与数据汇总链有效。
2. 单独测试主轮廓得到的8x8高稳定结果不能推广到全画面。主轮廓 ID 1 的8级相邻精确重复率为99.4728%，全部轮廓加权后只有67.2381%。
3. 8x8适合最快变化扫描，但不能区分存在身份。两段中只有63.8456%和65.4423%的帧没有跨 ID 精确值歧义，同一个8x8值最多被8个或15个 ID 共用。
4. 16x16可用于粗状态和二次筛选，但仍不是可靠身份特征。两段无歧义帧提升到91.8244%和93.0823%，仍存在跨 ID 完全相同值。
5. 32x32在本次13139条样本中没有出现跨 ID 精确碰撞；对两段均长期持续的8个 ID，双向跨回放唯一识别率达到99.6930%和99.1886%。因此32x32已具备“长期静态轮廓形状身份候选”的实用价值。
6. 32x32尚未通过全场景通用99%门禁。段内长期 track 的唯一识别率为98.8304%和99.2593%；加入接替和中期 track 后只有84.2839%和88.8778%。
7. 当前识别标签是观察 `contour_id`，不是经过人工裁决的现实存在身份。接替 ID 之间的“误识别”可能表示 tracker 换号，也可能表示轮廓不够可分，现有数据不能完全区分这两种原因。

因此，当前正确口径是：

> 压缩轮廓可以区分本次静态场景中的长期稳定存在候选，32x32是当前最有效层级；但压缩轮廓不能单独完成所有现实存在的最终身份裁决。

生产路径应采用：

```text
8级快速扫描
→ 16级粗状态筛选
→ 32级形状身份候选
→ 位置、尺寸、深度、运动、遮挡和历史联合门禁
→ 旧存在、接替track、新存在候选或未知
```

## 二、测试目标

本轮分别验证三个问题：

### 2.1 全轮廓稳定性

确认主轮廓之外的其他轮廓经过“内部全填充、居中、分级压缩”后，连续帧形状是否稳定，以及稳定程度是否与主轮廓一致。

### 2.2 跨轮廓可区分性

确认不同观察 ID 是否会产生完全相同的压缩值。若同一个压缩值被多个 ID 共用，则仅凭该值不能区分存在候选。

### 2.3 时间与跨回放识别

用前段帧建立每个轮廓的压缩模板，再识别后段帧或另一段回放中的轮廓，验证压缩特征是否保留足够的身份信息。

本轮不验证：

- 两个外形高度相似但现实身份不同的对象是否可区分；
- 未见过的新对象能否被正确拒绝为未知；
- 相机移动、对象移动、尺度改变或视角改变下的身份保持；
- 压缩轮廓能否单独确认现实存在。

## 四、数据与实现口径

### 4.1 闭合轮廓全填充

每条 `.b8x8` 轮廓先从外部洪泛背景，再把不与外部连通的内部黑洞全部填为前景，最后重新裁剪外轮廓。

该处理只用于测试“外剪影形状”。它不表示生产分割可以删除真实能看到背景的穿孔，也不修改现实深度事实。

### 4.2 正方形分级压缩

```text
闭合外轮廓内部全填充
→ 按同一轮廓ID的最大尺寸选择2次幂基础正方形
→ 居中放置，不使用原画面位置
→ 2x2面积池化逐级压缩
→ 每格占用率 >=50% 记为1，否则记为0
→ 行优先按位压缩
```

每个 ID 使用能容纳其全部样本的最小2次幂基础正方形。大轮廓不会被强行缩小到小轮廓的基础尺寸，小轮廓也不会被无条件拉伸到512级。

### 4.3 重复值身份边界

跨段统计重复值时使用 `(contour_id, digest)`。不同 ID 即使产生相同位图，也不能被统计为同一个存在；相同位图反而属于本轮需要发现的跨 ID 碰撞。

### 4.4 识别模板

对每个候选 ID：

1. 按时间取前50%帧；
2. 对每个压缩位做多数表决，形成一个二值模板；
3. 后50%测试帧与全部候选模板计算前景 IoU；
4. 只有正确模板严格高于所有其他模板，才计为“唯一正确”；
5. 与其他模板并列不算可区分。

该方法是闭集识别，即测试时真实 ID 必然在候选列表中。它尚未测试未知对象拒绝。

## 十、跨回放长期ID识别

跨回放只使用两段均覆盖至少90%帧的8个 ID。一段全部帧建立模板，另一段全部帧验收：

| 边长 | 第一段训练→第二段 | 第二段训练→第一段 | margin p05 |
|---:|---:|---:|---:|
| 8 | 97.5877% | 87.0833% | 7.1429% / 0% |
| 16 | 87.3684% | 87.1930% | -15.2778% / -1.4620% |
| 32 | 99.6930% | 99.1886% | 7.2368% / 7.1711% |

32级双向识别均超过99%，且最差5%样本的正确模板 margin 仍为正，是本轮最强的长期形状身份证据。

16级跨回放识别反而低于8级。原因是2x2面积池化后再使用50%二值阈值，会让阈值附近格子翻转并改变边界拓扑。分辨率提高并不保证任意单一指标严格单调改善。

跨回放测试仍有一项假设：相同长期数字 ID 在两段中代表对应的静态对象。该假设来自同场景和长期持续性，不是人工现实存在真值，后续必须补标注验证。

## 十一、面积、距离和画面位置

逐 track 数据已记录 bbox面积占比、前景占比、中位深度和距画面中心比例，并按连续帧对数计算加权相关。

以32级为例：

| 指标 | 面积占比相关 | 距离相关 | 距画面中心相关 |
|---|---:|---:|---:|
| 逐track IoU p50 | 0.2817 | 0.4943 | -0.3319 |
| 相邻精确重复率 | -0.4185 | -0.0044 | 0.2802 |

同一层级的两个稳定性指标已经出现不同方向，8/16/32级之间也不一致。因此当前混合场景没有形成可推广的“越大、越近或越靠中心就必然越容易区分”单变量规律。

对象身份、轮廓复杂度、遮挡、track生命周期、面积、距离和画面位置同时变化，属于混杂变量。本轮相关只用于提出后续控制实验，不作为因果结论或自动阈值依据。

## 十三、原因判断

### 已确认

1. 主轮廓的高稳定性不能代表其他轮廓。
2. 8级和16级存在真实跨 ID 精确碰撞。
3. 32级在当前两段中没有跨 ID 精确碰撞。
4. 32级对长期 ID 的识别明显高于对接替/中期 ID 的识别。
5. 接替 track 是当前总体识别率下降的主要集中区域。

### 尚不能确认

1. 32级是否能区分外形相近但现实身份不同的两个对象。
2. 接替 ID 混淆中有多少属于同一现实对象换号。
3. 相机或对象运动、遮挡、视角和尺度变化时，32级是否仍保持99%左右识别。
4. 当前结果能否推广到其他室内场景和更多对象类别。

## 十四、下一步测试

### P0：补现实存在真值

对当前两段回放人工登记现实存在标签与各时间段 `contour_id`、接替、分裂、合并和遮挡关系。先确认 `12/22/38/59` 和 `10/24/50/66` 是同一对象换号还是不同对象，才能准确解释段内识别率。

### P1：增加同形不同物体负样本

在同一画面放入两个外剪影接近的不同对象，验证32级是否错误合并。只测形状明显不同的对象不足以证明身份区分能力。

### P2：增加未知对象拒绝

训练模板中不放入一个测试对象，要求系统输出“未知/新存在候选”，而不是强制匹配最相似旧模板。需要测量最小IoU门槛、第一名与第二名 margin、未知拒绝率和错误接纳率。

### P3：增加视角、尺度和位置控制变量

让同一对象改变画面位置、距离、小角度旋转、相机缓慢平移和短时遮挡，测量32级模板的适用条件，而不是把当前静态结果直接推广到运动场景。

### P4：设计联合存在匹配

候选匹配至少应包含：

```text
32级形状相似度
+ bbox位置与尺寸变化
+ 深度区间或距离模式
+ 相机姿态补偿后的投影关系
+ 时间连续性与缓存年龄
+ 遮挡/重现关系
```

联合门禁通过后才能更新旧存在；形状相似但空间或时间门禁失败时，应保留为新存在候选或未知。

本轮没有修改C++处理逻辑，因此未重复执行 `msbuild`。测试依据为提交 `776133b` 中的Python分析器、聚合证据和已保存固定回放结果。

## 十七、最终判定

本轮不是“已经获得存在身份证”，而是完成了以下闭环：

```text
单轮廓稳定性
→ 全轮廓稳定性
→ 跨ID精确碰撞
→ 时间切分识别
→ 跨回放长期ID识别
→ 明确压缩层级适用范围
```

最终建议固定为：

```text
8x8：变化扫描特征
16x16：粗状态特征
32x32：长期静态形状身份候选特征
现实存在身份：联合多证据后再裁决
```

32x32是本轮最重要的有效结果，但它的适用范围必须保留“静态、长期、闭集、同场景”限定。下一阶段应优先补现实存在真值和未知对象拒绝，而不是继续只对当前静态分数调参。

## 十八、32x32轮廓直接相似度补充测试

在完成模板分类后，继续直接比较32x32位图的前景 IoU，目标是确认“同一候选”和“不同候选”的相似度分布是否存在可用阈值。

### 18.1 样本构造

```text
段内正样本：同一contour_id的连续帧
段内负样本：同一帧中的不同contour_id
跨段正样本：对齐帧中的共同长期ID
跨段负样本：对齐帧中的不同共同长期ID
```

| 范围 | 正样本 | 负样本 | 正样本IoU p05 / p50 / p95 | 负样本IoU p05 / p50 / p95 | AUC |
|---|---:|---:|---:|---:|---:|
| 两段全部track合并 | 13067 | 69334 | 23.3645% / 90.6977% / 100% | 4.0000% / 14.8810% / 48.9583% | 0.972306 |
| 两段长期track合并 | 10242 | 41040 | 63.6408% / 91.3793% / 99.7519% | 3.5714% / 14.5754% / 62.6506% | 0.989862 |

长期 track 的正负分布大部分可分，但正样本 p05 与负样本 p95 只相差约0.99个百分点，不存在完全无重叠的硬分界。

### 18.2 阈值扫描

| 范围 | 最佳平衡阈值 | TPR | FPR | 平衡准确率 | FPR<=1%阈值 | 对应TPR |
|---|---:|---:|---:|---:|---:|---:|
| 全部track合并 | 45.7% | 90.8242% | 5.3870% | 92.7186% | 69.8% | 80.8678% |
| 长期track合并 | 64.7% | 94.6983% | 3.4942% | 95.6021% | 71.5% | 90.4218% |
| 跨段共同长期ID | 47.2% | 98.7500% | 3.5871% | 97.5815% | 64.2% | 92.4342% |

第一段长期 track 选择的65.3%阈值固定迁移到第二段后，第二段 TPR 为93.7122%、FPR为3.2212%、平衡准确率为95.2455%；应用到跨段共同长期 ID 时，TPR为91.6447%、FPR为0.5420%。

使用71.7%严格阈值时，两段长期 track 合并 FPR 可降到0.8528%，但TPR也降到90.3827%；跨段TPR只有79.6053%。这证明严格阈值不能用于单独断开身份。

### 18.3 重叠来源

- 同 ID 低相似主要来自第二段 ID 8、第一段 ID 7和9，其 p05 约为17.38%、19.18%和20.83%。
- 不同 ID 高相似主要来自第一段 `9/10` 和第二段 `8/9`，两组 p50 均约70%，p95均为75%。
- `5/8/9/10` 等小轮廓组合也存在约62%的不同 ID 中位相似度。

这些重叠既可能来自真实不同对象外形相近，也可能来自同一现实对象被拆成多个观察 ID。没有现实存在真值前，不能把所有不同 ID 对都当成可靠负样本。

### 18.4 补充判定

本轮建议只形成三态实验口径：

```text
IoU >=72%：强形状匹配候选
IoU 65%-72%：弱形状匹配，必须联合位置/深度/历史复核
IoU <65%：明显形变或不同候选，不得仅凭此值立即断开身份
```

该阈值只适用于当前静态闭集材料，不进入生产默认配置。32x32直接 IoU 可以显著缩小候选范围，但单一阈值仍不能承担现实存在身份裁决。
