# D455 深度空间噪声与多帧收敛测试报告 v0.1

## 一、测试目标

本轮是静态稳定性研究的收尾测试，回答：

1. 连续帧深度噪声在空间上如何分布？
2. 简单平均是否能降低稳定区域噪声？
3. 深度孔洞通常持续多少帧，历史值最多复用多久？
4. 哪些像素禁止平均或填充？

## 二、输入与边界

| 项目 | 内容 |
|---|---|
| 数据集 | `datasets/static_stability_depth_spatial_013` |
| 设备 | Intel RealSense D455，固件 `5.14.0` |
| 场景 | 固定室内场景，相机和物体静止 |
| Stereo控制 | AE关闭，手动曝光30000 |
| 帧数 | 600 |
| 分辨率 | 640×480 |
| 同步 | settle 30/30通过，正式600/600通过，0拒绝 |
| 分析输入 | 原始未对齐 `depth16` 毫米图 |

有效深度定义为：

```text
0 < depth_mm < 65535
```

`0` 是无效深度；`65535` 是原始深度转换到16位毫米图后的饱和值。本数据首帧中，`0` 占约66.76%，`65535` 占约13.87%。如果把65535当成有效远距，会虚假提高稳定覆盖率并压低噪声统计，因此本轮及后续统一排除。

前300帧用于构造不同窗口估计，后300帧的逐像素中位数作为重复性参考。该参考不是真实距离真值，所以报告只能评价稳定性，不能评价绝对测距精度。

## 三、空间有效性分类

| 类型 | 像素比例 | 定义 |
|---|---:|---|
| 持续有效内部 | 16.37% | 有效率≥95%，且不在50mm深度边缘 |
| 持续有效深度边缘 | 0.054% | 有效率≥95%，且邻域中位深度差>50mm |
| 间歇深度 | 7.03% | 有效率5%–95% |
| 持续无效 | 76.54% | 有效率≤5% |
| 边缘跳变候选 | 0.327% | 深度边缘且时间p90-p10跨度>100mm |

当前场景包含大面积低纹理白墙、桌面、柜体和遮挡边缘，因此持续无效比例很高。这是该场景和当前原始深度配置的事实，不能直接泛化为所有D455场景。

## 四、噪声随距离增长

在持续有效内部区域中：

| 中位距离 | 时间标准差p50 | 时间标准差p95 |
|---|---:|---:|
| 0–1m | 2.53mm | 5.21mm |
| 1–2m | 9.27mm | 19.70mm |
| 2–3m | 18.50mm | 39.29mm |
| 3–5m | 26.50mm | 57.40mm |

结论：深度数值噪声随距离明显增大，不能为全距离使用同一个毫米误差门槛。允许范围应按距离分段或随距离增长。

## 五、简单平均是否有效

以下误差是相对后300帧中位数的重复性差异，统计范围为持续有效内部像素：

| 窗口 | 简单平均p50 | 简单平均p95 | MAD过滤平均p95 |
|---:|---:|---:|---:|
| 1帧 | 5.50mm | 40.25mm | 40.25mm |
| 2帧 | 4.38mm | 29.00mm | 29.00mm |
| 3帧 | 3.75mm | 24.42mm | 27.42mm |
| 4帧 | 3.38mm | 22.19mm | 23.75mm |
| 5帧 | 3.05mm | 20.30mm | 22.14mm |
| 8帧 | 2.63mm | 17.72mm | 18.59mm |
| 16帧 | 2.23mm | 15.00mm | 15.02mm |
| 32帧 | 1.98mm | 13.09mm | 12.61mm |

在已先验确认的持续有效内部区域，简单平均确实有效，且3–8帧时略优于当前MAD过滤参数；说明该区域主要是连续随机波动，短窗口内没有大量离群值。32帧时MAD过滤平均才略好于简单平均。

因此推荐：

```text
持续有效内部：3–5帧简单有效值平均。
检测到有限离群值或使用长窗口：再启用MAD过滤。
```

30Hz下3帧约100ms、5帧约167ms。更长窗口虽然继续改善稳定性，但延迟和运动残影成本明显增加。

## 六、孔洞恢复与历史复用

对所有最终恢复的无效连续段统计：

| 恢复时限 | 累计比例 |
|---:|---:|
| 1帧内 | 49.08% |
| 2帧内 | 66.34% |
| 3帧内 | 75.17% |
| 5帧内 | 84.03% |
| 10帧内 | 91.72% |

间歇深度像素的最长连续孔洞中位数为9帧，p95为60帧。也就是说，许多孔洞会很快恢复，但也存在长时间无效区域。

在间歇像素中，MAD过滤平均的窗口结果为：

| 规则 | 3帧覆盖 | 3帧p95误差 | 5帧覆盖 | 5帧p95误差 |
|---|---:|---:|---:|---:|
| 窗口内至少1个有效值 | 79.38% | 59.95mm | 88.33% | 56.88mm |
| 有效值达到窗口一半 | 55.22% | 46.39mm | 51.89% | 33.88mm |

因此，上一有效值最多复用3帧可以消除约75%的短闪烁事件，但它只能作为历史估计维持轮廓归属，不能作为当前帧精确深度。要求多数帧有效会降低覆盖率，但显著改善误差。

## 七、禁止直接平均的区域

边缘跳变候选即使增加窗口仍然不稳定：

| 窗口与支持规则 | 覆盖率 | p50误差 | p95误差 |
|---|---:|---:|---:|
| 1帧 | 69.73% | 90.50mm | 459.80mm |
| 3帧，有效值过半 | 70.12% | 72.96mm | 327.36mm |
| 5帧，有效值过半 | 70.89% | 66.17mm | 343.49mm |
| 32帧，有效值过半 | 70.26% | 34.08mm | 161.90mm |

这些像素很可能在前景、背景或多个表面之间切换。简单平均会生成现实中不存在的中间深度，因此必须：

```text
按彩图/深度边缘拆分表面；
或保留多个候选；
或将该像素标记为深度未知。
```

## 八、建议实现规则

```text
当前帧有效 + 持续有效内部：
  使用3–5帧简单有效值平均，标记为多帧稳定测量。

当前帧无效 + 历史3帧内有可靠值：
  可复用历史值维持归属，标记历史估计并衰减置信度。

窗口内有效值不足一半：
  不输出精确深度，只保留存在级距离区间。

深度边缘或跳变候选：
  禁止跨表面平均，优先拆分或保持未知。

连续全部无效或65535饱和：
  多帧平均无法恢复，使用彩图轮廓/双目粗距或Unknown。
```

每个像素应同时保存：

```text
估计深度
来源：当前测量/多帧平均/历史复用/模型推算
窗口有效支持数
深度MAD或方差
缓存年龄
是否边缘跳变候选
```

## 九、阶段结论

本轮确认：

> 简单平均可以显著降低持续有效内部像素的随机深度噪声，但不能解决持续无效区域，也不能安全处理前景/背景跳变边缘。3–5帧是当前30Hz静态条件下较实用的稳定窗口；历史值最多复用3帧可覆盖大多数短孔洞事件，但必须保留“历史估计”语义。

至此，全画面静态稳定性、同步、控制模式、空间噪声、平均收敛和孔洞持续长度已经形成第一轮闭环。下一阶段应停止继续扩大相机全局静态测试，进入“按彩图轮廓和局部表面逐像素补深度”的验证。
