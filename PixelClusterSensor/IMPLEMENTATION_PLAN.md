# 像素簇视觉外设实施阶段

日期：2026-09-08；2026-09-09 更新实机供包验证。范围只涉及 `D:\D455` 新子工程，不授予其它数字生命仓库的接口变更或接线权限。

## 目标

原始RGBD -> 可追溯像素簇、轮廓、颜色、观测深度和独立补全层 -> 自我合法读取与存在组织。第一阶段不做体素、世界身份、长期记忆和方法自动晋级。

## 下一步最小验证

最小实机链路已完成，见 [2026-09-09记录](../docs/codex_analysis/pixel_cluster_sensor_camera_20260909.md)。原始输入、设备标定和逐流时间保存在 `.codex_tmp/PixelClusterSensor/camera_20260909_final/`，不提交原始图片，不直接跑旧60条参数矩阵。

下一步先建立不修改传感器数值的预热观测门禁：实测首帧原始无效深度中位数74.40%，后续42.63%，尚未分离启动阶段、场景变化、曝光和SDK时间来源的影响。不应仅按固定等待秒数声明稳定。随后使用已知平面、深度台阶与有真实背景开口的目标进行短录制。原型的最近像素中心配准会产生缺测，需将配准采样不足、传感缺测、分割错误和补全错误分开计量；不能仅优化重建一致率。

实时可用性、物理深度准确性、目标身份连续性和数据供包分别验收。处理速度本轮仅记录，不宣称优于主工程，也不修改既有100ms评分门槛或任何best配置。
