# 像素簇视觉外设实施阶段

日期：2026-09-08；2026-09-09 更新实机供包验证。范围只涉及 `D:\D455` 新子工程，不授予其它数字生命仓库的接口变更或接线权限。

## 目标

原始RGBD -> 可追溯像素簇、轮廓、颜色、观测深度和独立补全层 -> 自我合法读取与存在组织。第一阶段不做体素、世界身份、长期记忆和方法自动晋级。

## 下一代聚簇核心路线

2026-09-21 冻结新的实现顺序：彩图闭合轮廓先形成可见簇，可靠深度只负责有证据的空间拆分和簇内距离/尺寸属性，随后执行有来源与年龄的短时深度稳定和 8/16/32 分级轮廓联合关联。`candidate_0030` 只作为旧主程序运行基线；差异扫描、缓存、ROI 和并发在核心质量通过后再接入。当前深度主导实现保留为回归对照，不直接晋级；当前轮廓主导实验路径也必须经过真实静态600帧×3、动态、遮挡、孔洞、斜面和未知拒绝门禁后才能提议切换默认值。详细阶段、数据结构和硬门槛见 [轮廓主导聚簇实现方案](../资料/20260921_D455轮廓主导深度约束时序稳定聚簇实现方案_v0.1.md)。

不重叠块时域估计已经用旧360帧及新采120帧复验，见 [估计层报告](../docs/codex_analysis/pixel_cluster_sensor_temporal_20260909.md)。新片段3/5/9帧平均将共同有效像素对照差p95从52mm降到29.7/23.4/17.4mm，最旧样本相应约66.7/133.4/266.7ms。这不是物理精度或真实边缘保持的验收；全图只有约65.8%像素进入条件化比较，边界缺测仍未覆盖。

2026-09-09 根据用户效率方向改试静态累积账本，不继续扩大平均窗口。当前深度优先写入，仅0缺测允许有限年龄历史候选；13组反例、Release/Debug回放及20份真实输出来源读回通过，详见 [静态累积报告](../docs/codex_analysis/pixel_cluster_sensor_accumulation_20260909.md)。这不是“所有历史永久有效”，也不是完整存在/轮廓记忆。

旧动态片段测试已经完成，见 [动态累积报告](../docs/codex_analysis/pixel_cluster_sensor_dynamic_accumulation_20260909.md)：全局颜色门禁几乎每帧重置，未产生历史候选；不是动态复用机制通过。旧室内数据时间缺口不能补造，车载数值时间戳也缺时间域，均只用于有明确限制的诊断。

下一步先区分局部变化与相机运动：局部变化仅局部失效，相机运动需要同簇关联/重投影，不可靠时保持降级。再用独立动态边界/对象证据确认“历史表面还占据当前像素”，测试错误滞留、失效及时性与源年龄，而不是单纯放宽全图门槛。通过后再讨论原始深度到配准像面的合同及C++影子接入。当前正常供包仍不启用累积/时域滤波，不改变50ms配对门槛或原始数值，不晋级best。

实时可用性、物理深度准确性、目标身份连续性和数据供包分别验收。处理速度本轮仅记录，不宣称优于主工程，也不修改既有100ms评分门槛或任何best配置。
