# 像素簇视觉外设实施阶段

日期：2026-09-08。范围只涉及 `D:\D455` 新子工程，不授予其它数字生命仓库的接口变更或接线权限。

## 目标

原始RGBD -> 可追溯像素簇、轮廓、颜色、观测深度和独立补全层 -> 自我合法读取与存在组织。第一阶段不做体素、世界身份、长期记忆和方法自动晋级。

## 下一步最小验证

连接D455后先运行 `--list-devices`，再用客户端采集1至3帧并独立读回，验证关闭后可再次打开。保留原始数据、设备标定及逐流时间，不直接跑旧60条参数矩阵。

随后使用已知平面、深度台阶与有真实背景开口的目标进行短录制。原型的最近像素中心配准会产生缺测，需将配准采样不足、传感缺测、分割错误和补全错误分开计量；不能仅优化重建一致率。

实时可用性、物理深度准确性、目标身份连续性和数据供包分别验收。处理速度本轮仅记录，不宣称优于主工程，也不修改既有100ms评分门槛或任何best配置。
