# 深度时域估计离线验证

日期：2026-09-09；基于 `75886f58`，分支 `codex/visual-capability-loop-plan`。本轮新增Python离线工具及测试，未修改C++、正常供包、相机参数或原始数据。

## 结论

**简单平均能够降低这类低变化片段的深度波动，但不能证明距离更准确，也不能全画面长期启用。** 旧三段数据与参数固定后新采的一段数据出现相近结果。平均窗口越长，波动越小，同时使用更早的样本；缺测、运动和物理边界的风险并未因此消失。

普通平均、中位数及带变化门禁中位数都保持离线探针。运动反例已证明，连门禁中位数也会在缓慢移动时输出落后的表面深度；本轮不选生产赢家，不新增best，不改变预热未证明稳定状态。

## 公平比较口径

- 旧材料三次各120帧；新材料一次120帧。各会话固定排除前30帧，只是实验排除，不是预热合格判断。
- 每18帧为一单元，拆成前后两个9帧半段。3/5/9帧估计分别使用各半段末N帧。所有方法输出在相同两个时刻，源时间相距约300ms。
- 对照为这两个时刻的原始深度值，不是把3帧方法的33ms差与9帧方法的300ms差混比。前后估计及不同单元之间没有共享样本；跨方法共享同一批材料是有意的配对设计。
- 公平像素集合要求18帧全部原始有效（排除0/65535），按第一个对照时刻原始深度分带。每个方法再次报告自身拒绝集合，并在自身保留的同一组像素上重算原始对照。
- 每对先计算像素绝对差的p95，再在时间单元上取中位数。旧材料每个组合15对，新材料5对；无置信区间，不把5对当作充分泛化证据。
- 旧集合平均占全图66.218%，新集合65.797%。结果不覆盖剩余缺测/范围外像素，不能称全画面噪声改善。
- 参数在新采前固定；新采只是相近现场的新片段，不是跨场景测试集，也没有独立绝对测距真值。

## 估计规则

三个窗口均要求最新原始深度有效、有效样本数至少ceil(0.8N)、所用有效样本均在[0.3,3.5)m内。缺失最新深度不允许用历史填上。估计写独立数组；原始值、样本数、拒绝原因与源帧保留，不递归使用前次估计。

`guarded_median` 另检查 `最大深度-最小深度 <= 0.04+0.02*最小深度`，以及窗口各彩图与末帧彩图的平均绝对差<=3、任一通道差>20的像素比例<=2%。彩图仅作全局否决，未冒用为原始深度像面的逐像素颜色对应。没有光流、姿态补偿、重投影或物体身份关联。

拒绝位：1当前缺测、2当前范围外、4样本不足、8时域深度跨度、16彩图变化、32历史范围外。多个拒绝位可以同时存在，其计数不能简单求和当成不重复拒绝像素数。

## 静态片段结果

普通平均对照相同，单位mm；表值均为“每对p95，再取时间中位数”：

| 窗口 | 旧材料原始差 | 旧材料平均后差 | 新材料原始差 | 新材料平均后差 | 新材料最旧支持样本年龄 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 3帧 | 52.0 | 29.3 | 52.0 | 29.7 | 66.7ms |
| 5帧 | 52.0 | 23.0 | 52.0 | 23.4 | 133.4ms |
| 9帧 | 52.0 | 17.3 | 52.0 | 17.4 | 266.7ms |

5帧平均在新片段的条件化对照差下降约55%，不等于精度提升55%。表中年龄是相对末帧源时间的支持集合跨度，不是算法计算耗时，也不是已校准的结果年龄；5帧支持集合的平均样本年龄约66.7ms。

新片段的中位数对照：

| 窗口 | 中位数差 | 门禁中位数差 | 门禁保留集合上的原始对照差 | 公平集合内门禁保留率 |
| --- | ---: | ---: | ---: | ---: |
| 3帧 | 35.0 | 32.0 | 47.0 | 96.33% |
| 5帧 | 29.0 | 24.0 | 44.0 | 92.44% |
| 9帧 | 22.0 | 17.0 | 40.0 | 86.32% |

门禁中位数排除了更不稳定的像素，因此不能把它的17.0mm直接与平均的17.4mm比较后选赢家。对应原始对照已从52mm变为40mm，保留率也下降到86.32%；其条件化收益与样本筛选须同时呈现。

新片段5帧平均的距离分带：

| 分带 | 原始对照差 | 平均后差 |
| --- | ---: | ---: |
| 0.3-1m | 6.0mm | 2.6mm |
| 1-2m | 37.0mm | 15.8mm |
| 2-3.5m | 70.0mm | 32.6mm |

边界/内部按原始深度跳变或有效性边界及一像素扩张分组，详细值在CSV；这只是算法边界，不是人工物体真值。新片段进入公平集合的边界像素仅占全图约2.45%，真实不稳定边缘可能已被共同有效条件排除，不能据此宣称真实边缘已保全。

## 已知真值反例

| 场景 | 结果与限制 |
| --- | --- |
| 最新深度缺失或65535 | 全部方法拒绝估计，原始无效码保留，不从历史填洞 |
| 固定1m/2m空间台阶 | 三方法均不混合相邻空间像素，台阶保持；不证明运动边界安全 |
| 5帧中仅一帧出现1.5m离群值，其余1m | 平均输出1.1m，中位数1m；门禁中位数拒绝估计 |
| 前4帧1m，末帧真实背景重现为2m | 平均1.2m，中位数1m，均混入旧表面；门禁拒绝且原始2m保留 |
| 每帧增加10mm，5帧从1.00m到1.04m，彩图不变 | 门禁中位数仍接受约1.02m，落后当前20mm；说明全局颜色和深度跨度门禁不足 |

工具测试通过包括正确暴露最后这个失败，不代表方法安全门禁通过。当前没有把“拒绝估计”转换为丢弃轮廓或删除像素；独立估计无效时，本帧原始材料仍可由未来正式调用方使用。
