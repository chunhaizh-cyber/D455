# 静态累积账本探针与验证

日期：2026-09-09。基线 `042581d3`，分支 `codex/visual-capability-loop-plan`。按用户要求改试“保留已有信息，用当前帧修正，再输出当前融合结果”。仅新增Python逐帧深度累积探针和测试，未改变C++、正常供包、自我协议、分割或best配置。

## 结论

**这一路线在本次材料上降低了缺测状态闪烁和Python处理开销，但没有降低当前有效深度的数值噪声。** 它与多帧平均解决的不是完全相同的问题，不能以更快直接判定全面更优。

本版不做加权平均：当前有可用测量就直接修正账本，当前缺测才保留满足门禁的历史值。因此当前新表面一旦被测到，就不会被旧平均值拖住；但新表面恰好没有深度、颜色也没有可检测变化时，仍可能保留旧值，必须标记为历史候选。

“历史不丢”不能等于“历史永远在当前画面有效”。本次原始录制文件全部保留且不修改；活动账本只保留每像素最近的合格观测及有限支持信息，超龄/冲突时停止输出旧值，不删除原始证据。这个缓存本身不是无损历史档案，也不是存在级长期记忆。

## 逐帧规则

1. 新会话重新建立账本，默认没有深度；当前彩图总是来自本帧，不用旧彩图覆盖。
2. 当前有[0.3,3.5)m深度：写入最新原始值、最近实测时间和源帧索引；不与旧值平均。范围资格不代表物理精度已获保证。
3. 当前为0缺测：仅在同一像素已积累至少3次相容观测、距最近实测不超过200ms、且当前未触发失效时，输出历史候选。历史输出不增加观测次数、不更新实测时间，避免历史自行延寿。
4. 65535饱和或当前范围外数值原样保留，并清除该像素旧近场缓存，不以历史值替换当前反证。
5. 当前与缓存深度差超过 `0.04 + 0.02 * min(当前深度米, 缓存深度米)` 时，清除冲突像素及3x3邻域旧缓存，再用当前可用观测重新建立支持。
6. 彩图相对本轮静态参考图的平均通道绝对差>3，或任一通道差>20的像素超过2%，整份活动账本重置。使用固定参考图而非只比较上一帧，可检测累积颜色漂移；但仍不是相机姿态估计。
7. 源帧号缺口、异常事件、时间域/曝光元数据变化、重复/倒退或超过50ms的时间间隔会重置。单帧RGBD本身配对不合格则拒绝分析，不默许异步配对。

彩图与原始深度不在同一配准像面，所以彩图仅用于全局否决，绝不将彩图同坐标像素当作该深度像素的颜色证据。没有光流、IMU、相机重投影或实例关联；这些门禁不能证明画面物理静止。

## 输出与接口

`StaticAccumulator.update()` 每帧返回独立数组快照和诊断；状态占用不随帧数增长。现阶段在原始深度像面处理，不缓存簇标签或外围轮廓，不改 `PCS.Observation/1`。

| 字段 | 内容 |
| --- | --- |
| `raw_depth16` | 本帧原始深度，包含原始无效码 |
| `color_rgb` | 本帧完整彩图，仍在原始彩图坐标系 |
| `combined_depth16` | 当前优先、缺测时可加历史候选的累积图；单位见原始标定 |
| `evidence_state` | 0缺测、1当前范围内观测、2历史候选、3当前范围外观测、4当前饱和 |
| `source_index` | 值来自本会话原始帧列表的哪个索引；无值为-1，不是RealSense原生帧号 |
| `last_observation_age_ms` | 历史值距最近实测的源时间差；不是处理延迟 |
| `support_count` | 当前活动像素的支持次数，封顶3；不是概率置信度 |

不允许只读取累积图而忽略状态。历史候选不得当作当前精确深度送给自我；真正接入正常供包需要单独定义配准后来源与时效合同。像素缺深度不代表彩图像素或存在消失，本探针不删除任何像素或轮廓。

## 实验口径

- 使用已录制的三段360帧材料，再用另一段120帧复验。本轮没有重新拍摄；第二段此前用于时域估计测试，不是从未查看过的独立最终验收集。
- 参数预先固定，没有根据本次复验结果调阈值。每个会话前30帧参与账本建立，但排除在统计外；排除启动帧不代表预热稳定已通过。
- 对每段运行3次顺序重复，整段累积法和整段3帧平均交替先后，不并发跑候选。两法只对同一输出时刻有结果的帧报告处理计时。
- 计时包含对应Python处理、门禁和返回数组拷贝，不含PNG读盘/解码/哈希、源清单检查、统计与导出。它不是C++实现极限，也不是从曝光到发布的结果年龄，更不是完整系统帧耗时。
- 3帧平均使用上一版 `temporal_estimator.estimate(..., mean)`，连同堆栈构建计时。它生成估计、拒绝和年龄等数组；累积法生成当前彩图与融合数组。两者功能不同，比较只是当前两个探针的实际成本对照，不证明算法的通用速度比。
- 质量只统计第一次运行，三次运行同一材料不算三份独立质量样本。逐帧统计取时间中位数；深度差指标是“每对相邻帧共同当前有效像素差p95，再取时间中位数”，不是绝对测距误差，也不是上一轮约300ms间隔的独立块差。

## 测量结果

| 指标，时间中位数 | 三段旧材料，270个统计帧 | 另一段复验，90个统计帧 |
| --- | ---: | ---: |
| 当前范围内观测占全图 | 68.739% | 68.291% |
| 额外历史候选占全图 | 1.050% | 1.033% |
| 当前加历史的可提供数值比例 | 69.787% | 69.326% |
| 原始可用/缺测状态翻转 | 1.575% | 1.630% |
| 累积后可用/缺测状态翻转 | 0.527% | 0.599% |
| 当前共同有效点原始深度差p95 | 52mm | 53mm |
| 同一批点累积输出深度差p95 | 52mm | 53mm |
| 每帧历史值年龄p95的时间中位数 | 166.0ms | 133.5ms |
| 历史点再次测到时，新旧值差p95的时间中位数 | 30.8mm | 36.0mm |

累积图状态翻转下降是“用历史值延续显示”带来的效果，不是传感器缺测本身减少。始终没有合格深度、范围外或已超龄的部分仍然没有近场数值，本次约30.7%的图面未被累积法解决。历史点再次被测到时也存在差异，不能证明保留的旧值与真实当前表面一致。

| 数据 | 累积法三次p95，ms | 3帧平均三次p95，ms | 两组三次p95中位数之比 |
| --- | --- | --- | --- |
| 旧材料 | 14.35 / 15.79 / 15.09 | 18.97 / 18.84 / 22.04 | 累积法低约20.5% |
| 复验材料 | 13.46 / 13.58 / 13.36 | 17.83 / 17.78 / 17.66 | 累积法低约24.3% |

640x480时活动状态数组为5,529,600字节，约5.27MiB，与时间长度无关；返回快照和计算临时数组另计。基准运行器为了隔离IO而预载一段材料，最多512MiB；这不属于累积状态。此实现仍每帧扫描全图，复杂度O(像素数)，并没有做到只处理变化ROI，也未测完整进程峰值内存。

本机环境为Python 3.12.14、NumPy 2.3.5、Windows 11 build 26200；未隔离其它系统后台负载，未提供置信区间。不能从13ms推断整套观察/分割/写盘链路已达到30fps。

## 反例与读回

13组单元测试及Release/Debug原始回放集成通过，包括新值立即覆盖、缺测复用、年龄不递归刷新、200ms超龄、一帧支持不足、永久缺测、范围外/饱和保留、边界邻域失效、颜色漂移、源缺口、状态内存有界和输入/快照不被改写。

慢移已知值每帧增加10mm时，当前有深度的输出与本帧逐值相同，不再出现平均产生的20mm滞后。但“同色替换目标且该点无新深度”的反例中，仍输出旧表面的历史候选，直到失效或超龄。这个反例被测试正确暴露，**不是方法安全门禁通过**。200ms只是试验上限，不是所有运动场景可接受的延迟。

合成集成逐帧导出48份快照；真实材料每30帧及末帧抽样，共20份NPZ。独立读回核对了全部原始值/当前彩图，以及50,818个历史像素观测的具体来源值和年龄：旧材料38,054个，复验12,764个。通过只能证明来源没有伪造，不能证明旧表面仍存在。原21组协议回归及旧时域11组单元测试保持通过。

## 阶段判断

静态累积的逐帧更新、证据分层、失效和读回机制已验证；在这些低变化材料上有降低缺测闪烁与探针开销的信号。真实相机/物体运动、遮挡重现、配准后边界和完整观察包消费者尚未验证，所以不接入默认供包，不运行或冒充既有固定候选评分门禁，不修改100ms硬门槛，不晋级best。

下一步应专门用真实运动/遮挡材料检验“历史候选是否滞留在错误表面”，再决定是否把局部累积移入C++影子路径；不以扩大历史寿命换取虚假的全图完整率。
