# 全填充轮廓正方形分级压缩与比较

## 目标

该诊断用于验证以下静态轮廓表示：

1. 对闭合外轮廓采用内部全部填充，不保留内部深度孔洞、确认穿孔或临时黑洞。
2. 消除轮廓在原画面中的位置，只保留外剪影形状。
3. 把轮廓放入边长为8的正整数倍的正方形。
4. 分级压缩并逐级比较，最小为8x8。

该方法只测试外剪影稳定性。真实能看到背景的穿孔仍属于最终像素归属事实，不能因为本诊断填洞而在生产输出中删除。

## 处理流程

```text
.b8x8填充轮廓
→ 从外部洪泛背景
→ 把所有封闭黑洞填为前景
→ 重新裁剪外轮廓bbox
→ 居中放入下一2次幂正方形
→ 2x2面积池化逐级压缩
→ 每级生成二值特征和占用特征
→ 同ID连续帧逐级比较
```

正方形边长选择能容纳该轮廓全部样本的最小2次幂，因此天然是8的正整数倍。本轮主轮廓最大尺寸小于512，使用：

```text
512 → 256 → 128 → 64 → 32 → 16 → 8
```

轮廓不会在基础512级被拉伸；只做居中补黑。后续每级由连续2x2区域的平均占用率生成。

## 两类特征

### 二值特征

每格占用率 `>=50%` 记为前景，否则记为背景，再按行优先逐位压缩。

- 512级：32768 bytes
- 256级：8192 bytes
- 128级：2048 bytes
- 64级：512 bytes
- 32级：128 bytes
- 16级：32 bytes
- 8级：8 bytes

二值特征用于计算前景IoU和精确重复值。8x8相对512x512按位载荷压缩4096:1。

### 占用特征

每格保留0-255量化占用率，用于计算：

```text
占用相似度 = 100 * (1 - 所有格的平均绝对占用差)
```

占用特征可以揭示二值阈值后被隐藏的小幅面积变化。二值值相同不代表占用值相同。

首次二值重复出现于：

- 64级：第一段 frame 507 与 frame 542；
- 32级：第一段 frame 34 与 frame 41；
- 16级：第一段 frame 31 与 frame 32；
- 8级：第一段 frame 30 与 frame 31。

所有级别的0-255占用特征仍然是1140帧1140种值，占用相似度p50约99.40%-99.45%。这说明原始轮廓的连续面积差异没有消失，只是在粗二值阈值后归并为少量离散形状。

128级二值IoU没有单调优于256级，是50%阈值附近的格子发生翻转造成的量化混叠；因此不能假设分辨率越低，所有统计指标都会单调改善。

## 当前判断

- 512-128级仍保留几乎全部高维变化，没有精确重复。
- 64级开始出现少量重复，但不足以作为稳定模板。
- 32级已经显著归并形状，可用于中等粒度候选比较。
- 16级在信息量和稳定性之间形成明显过渡。
- 8级适合极粗的快速变化扫描，但只有2种二值值，不能承担精细轮廓确认。
- 生产使用时应先用8/16级快速比较，再在变化触发后回到32/64级或原始轮廓复核，不能只保留8x8结果。

## 全轮廓扩展测试

单独测试 `contour_id=1` 只能证明一个大轮廓的压缩稳定性，不能代表同一画面中的其他轮廓。全轮廓测试使用：

```powershell
python .\scripts\analyze_all_hierarchical_filled_contours.py `
  --input-dir=analysis_runs\binary_contour_static_long_repeat_001 `
  --input-dir=analysis_runs\binary_contour_static_long_repeat_recheck_001 `
  --output-dir=analysis_runs\hierarchical_filled_contour_all_001 `
  --min-side=8
```

输出：

```text
all_contours_per_track.csv
all_contours_per_contour.csv
all_contours_level_metrics.csv
all_contours_pair_metrics.csv
all_contours_summary.json
all_contours_report.md
```

批量比较遵守以下身份和时间边界：

- 每个轮廓 ID 按自身最大外轮廓尺寸选择基础正方形，不把小轮廓强行放大到512级。
- 只比较同一回放段、同一轮廓 ID、`previous_gap_frames == 1` 的连续帧。
- 不比较两个回放段边界处的相邻帧。
- 跨段重复值以 `(contour_id, digest)` 计数；不同 ID 的位图即使相同，也不视为同一存在。
- 汇总按实际帧数和连续帧对数加权，不让只有几帧的短 track 与570帧长期 track 等权。

90%段覆盖率作为长 track 门槛。两段测试共得到53个不同轮廓 ID、72个段内 track、13139条轮廓帧记录和13067个8级连续帧对：

### 长期轮廓并非都等同于主轮廓

两段均长期持续的 ID 为 `1,2,3,4,5,6,7,9`。主轮廓 ID 1 的8级相邻精确重复率为99.4728%，但 ID 5 和 ID 9 分别只有38.6643%和34.7979%。因此：

- 8级适合快速候选扫描，但不能统一承诺所有静态轮廓达到99%精确重复。
- `IoU p50=100%` 也不能代替精确重复率；p50只说明至少一半连续帧对相同或高度重叠。
- 低稳定 track 需要回到16/32级占用值、原始轮廓和身份连续性复核，不能仅靠8级位图裁决存在消失或出现。

### 面积、距离和画面位置

批量脚本把每个 track 的面积占比、中位深度和距画面中心比例写入逐 track CSV，并按连续帧对数计算加权相关。当前静态场景中，相关系数的方向会随层级和指标变化。例如32级 IoU p50 与面积、距离、中心半径的相关分别为 `0.2817 / 0.4943 / -0.3319`，而32级精确重复率对应为 `-0.4185 / -0.0044 / 0.2802`。

这说明当前样本中没有可直接推广的“越近、越大或越靠中心就必然越稳定”单变量规律。不同现实物体、边界复杂度、局部遮挡和 track 接替是混杂因素；这些相关只用于提出后续分层实验，不能解释为因果。

## 全轮廓结论

- 单一大轮廓的8级99.47%结果是真实局部结果，但不是全画面通用结果。
- 长期持续组总体优于单段长期组，说明身份连续性和轮廓生命周期必须进入稳定性门禁。
- 全部轮廓在8级只有67.2381%相邻精确重复；生产扫描应容许8级粗候选变化，并用16/32级和原始证据复核。
- 下一轮若要建立按距离、大小或画面位置自适应的阈值，必须采集控制变量数据，而不能直接从当前混合场景拟合规则。
- 压缩值能否区分不同轮廓属于另一项门禁，碰撞与身份识别结果见 `docs/COMPRESSED_CONTOUR_DISCRIMINATION.md`。
